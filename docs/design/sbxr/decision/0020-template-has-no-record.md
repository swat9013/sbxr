# 0020. template の記録を持たず、有無と作成日時を実行基盤の一覧から読む

- Status: Accepted
- Date: 2026-11-19
- 覆す条件: 実行基盤の template の一覧が、save した時刻を返さないとき

## 決定

- sbxr は template の記録を host に持たない（decision/0004 の「記録の置き場」を置き換える）
- template の有無と作成日時は、実行基盤の template の一覧から読む。出所の hash と cache 層の hash は tag から読む
- 期限（decision/0005）は、一覧が返す作成日時で判定する

## 根拠

- 記録と image が食い違う状態（記録はあるが image が無い、image はあるが記録が無い）が起こりえなくなる
- 利用者が `sbx template rm` で消しても、片付ける記録が残らない

## 却下した代替案

- 状態ディレクトリとは別の置き場に記録を置く（decision/0004）: 食い違いを直す分岐が create に要る
- 作成日時を tag に埋める: 期限で作り直すたびに tag が変わり、同じ tag を付け替える（decision/0005）ができない

## 見直し条件

置かない（境界の置き方の決定で、実行の記録から測れる量が無い）
